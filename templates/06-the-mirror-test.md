## For a team

Run it on the roadmap instead of the calendar: for each project, would the team want to work on it if this
were the last quarter? **Our suggestion:** three *no* quarters in a row on the same project make it a
candidate for `templates/01-the-say-no-list.md`.

**Note:** this is a tool for choosing work. If the no's are about health, safety or how you're being treated,
talk to someone you trust; that's outside what this playbook covers.
